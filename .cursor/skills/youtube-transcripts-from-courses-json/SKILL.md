# Транскрипты YouTube: courses.json → папка курс

## Источник данных

- Единственный источник уроков и ссылок: `backend/data/courses.json`.
- Для каждого **курса** используй поле **`contentFolder`** — имя подпапки в `курс/`.
- Для каждого **урока** бери:
  - `video_url` — вставлять на [tubetranscript.com/ru](https://tubetranscript.com/ru/)
  - `lessonNumber`, `title`, `youtubeId` — путь и метаданные в файле

## Путь к файлу

```
курс/<contentFolder>/<lessonNumber> урок/<youtubeId>.txt
```

Пример: `contentFolder` = `щенок`, урок 1, `youtubeId` = `a-pnVSz_rus` → `курс/щенок/1 урок/a-pnVSz_rus.txt`

Перед записью создай недостающие каталоги.

## Сайт tubetranscript

1. Открой `https://tubetranscript.com/ru/`.
2. Вставь в поле ввода **`video_url`** урока (из JSON).
3. Запусти получение транскрипта (кнопка вроде «Создать транскрипт»).
4. Дождись текста; при необходимости убери служебные строки интерфейса, оставь связный текст транскрипта (временные метки можно сохранить или убрать — по запросу пользователя; по умолчанию сохраняй как выдаёт сервис).

Реализация: агент с доступом к браузеру (MCP/автоматизация) или ручные шаги пользователя. Обычного HTTP GET страницы недостаточно — нужна отправка формы/ожидание результата в UI.

## Содержимое txt

- Кодировка: **UTF-8**.
- Рекомендуемая шапка (первые строки файла):

```
Курс: <title курса из JSON>
Урок: <title урока>
URL: <video_url>

```

Далее — тело транскрипта.

## Перезапись файлов

- **По умолчанию** не перезаписывай существующий `.txt` без явного указания пользователя (сообщи, что файл уже есть).
- Если пользователь просит обновить все или конкретный урок — перезапиши согласно запросу.

## Ошибки и краевые случаи

- Нет субтитров / пустой результат / ошибка сайта — сообщи пользователю, укажи `slug`, `lessonNumber`, `video_url`; не помечай урок как выполненный.
- Капча, блокировка, долгий таймаут — остановись, опиши проблему; при массовой выгрузке можно предложить продолжить с пропущенных уроков.
- Сервис не аффилирован с YouTube; соблюдай права на контент и условия использования сервиса.
