# Чеклист транскриптов по courses.json

Используй при массовой выгрузке: отмечай прогресс после сохранения `курс/<contentFolder>/<N> урок/<youtubeId>.txt`.

Поля из JSON: `contentFolder`, `lessonNumber`, `youtubeId`, `video_url`.
