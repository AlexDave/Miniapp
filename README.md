# DogCourse - Приложение для обучения собак

## 🐕 Описание

DogCourse - это современное веб-приложение для обучения владельцев собак. Приложение предоставляет курсы, треки обучения, систему достижений и чат для общения с экспертами.

## ✨ Функциональность

### 🎓 Обучение
- **Курсы** - структурированные программы обучения
- **Треки** - ежедневные задания и цели
- **Задачи** - конкретные упражнения и уроки
- **Прогресс** - отслеживание результатов обучения

### 🏆 Геймификация
- **Достижения** - система наград и бейджей
- **Уровни** - прогрессия пользователя
- **Опыт** - накопление очков опыта
- **Серии** - отслеживание дней подряд

### 👤 Профиль
- **Профиль питомца** - информация о собаке
- **Статистика** - детальная аналитика обучения
- **Настройки** - персонализация приложения
- **Аватар** - загрузка фото питомца

### 💬 Коммуникация
- **Чат** - общение с экспертами
- **Уведомления** - важные события и напоминания
- **Поддержка** - помощь пользователям

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd minapp
```

### 2. Настройка Backend

```bash
cd backend
npm install

# Создайте файл .env
echo "DATABASE_URL=\"postgresql://username:password@localhost:5432/dogcourse\"" > .env
echo "JWT_SECRET=\"your-secret-key\"" >> .env
echo "PORT=3001" >> .env

# Инициализация базы данных
npm run db:setup

# Запуск сервера
npm run dev
```

### 3. Настройка Frontend

```bash
cd frontend
npm install
npm run dev
```

## 📊 База данных

### Полная схема данных включает:

#### Основные сущности
- **Пользователи** - профили владельцев собак
- **Курсы** - программы обучения с задачами
- **Треки** - ежедневные цели и задания
- **Достижения** - система наград
- **Уведомления** - система оповещений

#### Связующие таблицы
- **Прогресс по курсам** - отслеживание обучения
- **Прогресс по задачам** - выполнение упражнений
- **Прогресс по трекам** - ежедневные цели
- **Достижения пользователей** - полученные награды
- **Сообщения чата** - история общения

### Тестовые данные
Скрипт инициализации создает:
- 3 тестовых пользователя с профилями
- 4 курса с задачами (Дрессировка, Здоровье, Поведение, Спорт)
- 4 трека обучения (30 дней, Неделя, Месяц, Спорт)
- 8 достижений с условиями получения
- Случайный прогресс обучения
- История сообщений в чате

## 🎯 API Endpoints

### Основные
- `GET /api/courses` - все курсы
- `GET /api/tracks` - все треки
- `GET /api/achievements` - все достижения

### Пользовательские
- `GET /api/user/progress` - прогресс пользователя
- `GET /api/user/courses` - курсы пользователя
- `GET /api/user/tracks` - треки пользователя
- `GET /api/user/achievements` - достижения пользователя

## 🐛 Решение проблем

### Ошибка подключения к БД
1. Проверьте DATABASE_URL в .env
2. Убедитесь, что PostgreSQL запущен
3. Создайте базу данных dogcourse

### Ошибка миграции
```bash
cd backend
npm run db:reset
npm run db:setup
```

### Ошибка Prisma
```bash
cd backend
npm run db:generate
```
