# ТЗ для иллюстраций к шагам теории

Цель — **функциональные** картинки: поза собаки и человека, направление движения, типичная ошибка, триггер окружения. Не декоративные «маскоты».

## Формат в данных

- Поля шага урока: `image_url` (URL или путь после выкладки в `backend/public/lesson-images/`), `image_role` (`hero` | `inline` | `caption`), `alt_text` (обязательно для доступности).
- Роли в контенте: по желанию дублируют смысл `image_role` для редакторов (`pose`, `movement`, `antipattern`, `trigger`, `time`).

## Технические ограничения

- Горизонталь 16:9 или квадрат; для inline — ширина до ~900px, вес файла разумный для мобильной сети.
- Прозрачный фон не обязателен; единый светлый фон серии допускается.

## Пилот

Первые **5 уроков** с осмысленными иллюстрациями — согласовать список уроков с владельцем продукта после выбора атомов из `atomic-lessons.json`.

## Демо-видео / GIF (спринт 19)

Поля шага в БД: **`media_type`** (`image` | `gif` | `video`), **`media_url`**, **`poster_url`** (постер и fallback при ошибке видео).

### Технические цели для роликов

- **Длительность:** 3–5 с (цикл для `loop` — короткий клип).
- **Разрешение:** до **480p** по высоте, 16:9 или квадрат.
- **Вес:** ориентир **≤ 500 KB** на шаг (для мобильной сети в Telegram).
- **Звук:** **без звука** (в плеере всегда `muted` + `playsInline`).

### Раздача файлов

- Каталог репозитория: **`backend/public/lesson-media/`** (раздаётся с корня API как **`/lesson-media/...`**).
- Заголовки: `Cache-Control: public, max-age=604800` (неделя + `stale-while-revalidate`).

### Фронт

- Видео: `<video autoplay loop muted playsinline>`, подгрузка по **IntersectionObserver** (не качаем всё заранее).
- При ошибке сети/кодека — **постер** или **`image_url`**, иначе текст «Видео не загрузилось».
