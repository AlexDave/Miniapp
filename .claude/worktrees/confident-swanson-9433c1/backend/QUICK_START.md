# Быстрый старт - Backend DogCourse

## 🚀 Быстрая настройка за 5 минут

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка базы данных
Создайте файл `.env` в папке `backend`:

```env
DATABASE_URL="postgresql://username:password@localhost:5432/dogcourse"
JWT_SECRET="your-secret-key-here"
PORT=3001
```

### 3. Инициализация БД
```bash
npm run db:setup
```

### 4. Запуск сервера
```bash
npm run dev
```

## 🔧 Полезные команды

```bash

npm run db:seed

# Только миграция схемы
npm run migrate
```

## 📊 Структура данных

### Основные таблицы
- `users` - пользователи
- `profiles` - профили с питомцами
- `courses` - курсы обучения
- `tasks` - задачи в курсах
- `tracks` - треки обучения
- `achievements` - достижения
- `notifications` - уведомления

### Связующие таблицы
- `user_tasks` - прогресс по задачам
- `user_tracks` - прогресс по трекам
- `course_progress` - прогресс по курсам
- `user_achievements` - полученные достижения
- `user_notifications` - уведомления пользователей
- `chat_messages` - сообщения чата

## 🎯 API Endpoints

### Основные
- `GET /api/courses` - все курсы
- `GET /api/tracks` - все треки
- `GET /api/achievements` - все достижения

### Пользовательские
- `GET /api/user/progress` - прогресс пользователя
- `GET /api/user/courses` - курсы пользователя
- `GET /api/user/tracks` - треки пользователя
- `GET /api/user/achievements` - достижения пользователя

## 🐛 Решение проблем

### Ошибка подключения к БД
```bash
# Проверьте DATABASE_URL в .env
# Убедитесь, что PostgreSQL запущен
# Создайте базу данных dogcourse
```

### Ошибка миграции
```bash
# Сбросьте БД и создайте заново
npm run db:reset
npm run db:setup
```

### Ошибка Prisma
```bash
# Перегенерируйте клиент
npm run db:generate
```
