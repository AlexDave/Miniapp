# Backend API для DogCourse

## Описание

Backend API для приложения обучения собак с полной функциональностью:
- Пользователи и профили
- Курсы и задачи
- Треки обучения
- Достижения
- Уведомления
- Чат
- Прогресс обучения

## Технологии

- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- JWT аутентификация

## Установка и настройка

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных

Создайте файл `.env` в корне backend директории:

```env
DATABASE_URL="postgresql://username:password@localhost:5432/dogcourse"
JWT_SECRET="your-secret-key"
PORT=3001
```

### 3. Инициализация базы данных

#### Вариант 1: Полная настройка (рекомендуется)
```bash
npm run db:setup
```

Этот скрипт выполнит:
- Миграцию базы данных
- Создание всех таблиц
- Заполнение тестовыми данными

#### Вариант 2: Пошаговая настройка

```bash
# 1. Применить миграции
npm run migrate

# 2. Заполнить тестовыми данными
npm run db:seed
```

### 4. Запуск сервера

```bash
# Режим разработки
npm run dev

# Продакшн режим
npm start
```

## Структура базы данных

### Основные модели

#### User (Пользователь)
- `id` - уникальный идентификатор
- `telegram_id` - ID пользователя в Telegram
- `name` - имя пользователя
- `email` - email пользователя
- `created_at` - дата создания
- `updated_at` - дата обновления

#### Profile (Профиль)
- `user_id` - связь с пользователем
- `pet_name` - имя питомца
- `avatar` - аватар пользователя
- `level` - уровень пользователя
- `experience` - опыт пользователя
- `total_courses` - общее количество курсов
- `completed_courses` - завершенные курсы
- `streak` - серия дней обучения
- `bio` - биография
- `preferences` - настройки (JSON)

#### Course (Курс)
- `title` - название курса
- `description` - описание
- `duration` - продолжительность
- `rating` - рейтинг
- `difficulty` - сложность
- `category` - категория
- `image` - изображение курса
- `video_url` - ссылка на видео
- `content` - содержимое курса
- `is_active` - активен ли курс

#### Task (Задача)
- `course_id` - связь с курсом
- `title` - название задачи
- `description` - описание
- `required_per_day` - требуемое количество в день
- `available_until` - доступно до
- `order_index` - порядок в курсе
- `is_active` - активна ли задача

#### Track (Трек)
- `title` - название трека
- `description` - описание
- `category` - категория
- `difficulty` - сложность
- `duration_days` - продолжительность в днях
- `is_active` - активен ли трек

#### Achievement (Достижение)
- `name` - название достижения
- `description` - описание
- `icon` - иконка
- `color` - цвет
- `condition` - условия получения (JSON)
- `is_active` - активно ли достижение

#### Notification (Уведомление)
- `title` - заголовок
- `message` - сообщение
- `type` - тип (info, success, warning, error)
- `is_read` - прочитано ли

### Связующие модели

#### UserTask (Прогресс по задаче)
- `user_id` - пользователь
- `task_id` - задача
- `completed_today` - выполнено сегодня
- `last_completed_at` - последнее выполнение
- `progress` - прогресс (0-100%)
- `is_completed` - завершено ли

#### UserTrack (Прогресс по треку)
- `user_id` - пользователь
- `track_id` - трек
- `days_remaining` - дней осталось
- `completed_today` - выполнено сегодня
- `last_completed_at` - последнее выполнение
- `is_completed` - завершено ли
- `started_at` - когда начат
- `completed_at` - когда завершен

#### CourseProgress (Прогресс по курсу)
- `user_id` - пользователь
- `course_id` - курс
- `progress` - прогресс (0-100%)
- `is_completed` - завершен ли
- `started_at` - когда начат
- `completed_at` - когда завершен
- `last_activity` - последняя активность

#### UserAchievement (Достижения пользователя)
- `user_id` - пользователь
- `achievement_id` - достижение
- `earned_at` - когда получено

#### UserNotification (Уведомления пользователя)
- `user_id` - пользователь
- `notification_id` - уведомление
- `is_read` - прочитано ли
- `read_at` - когда прочитано

#### ChatMessage (Сообщения чата)
- `user_id` - пользователь
- `message` - сообщение
- `is_bot` - от бота ли
- `created_at` - когда отправлено

## API Endpoints

### Пользователи
- `GET /api/users` - получить всех пользователей
- `GET /api/users/:id` - получить пользователя по ID
- `POST /api/users` - создать пользователя
- `PUT /api/users/:id` - обновить пользователя
- `DELETE /api/users/:id` - удалить пользователя

### Курсы
- `GET /api/courses` - получить все курсы
- `GET /api/courses/:id` - получить курс по ID
- `POST /api/courses` - создать курс
- `PUT /api/courses/:id` - обновить курс
- `DELETE /api/courses/:id` - удалить курс

### Треки
- `GET /api/tracks` - получить все треки
- `GET /api/tracks/:id` - получить трек по ID
- `POST /api/tracks` - создать трек
- `PUT /api/tracks/:id` - обновить трек
- `DELETE /api/tracks/:id` - удалить трек

### Достижения
- `GET /api/achievements` - получить все достижения
- `GET /api/achievements/:id` - получить достижение по ID
- `POST /api/achievements` - создать достижение
- `PUT /api/achievements/:id` - обновить достижение
- `DELETE /api/achievements/:id` - удалить достижение

### Прогресс пользователя
- `GET /api/user/progress` - получить прогресс пользователя
- `GET /api/user/courses` - получить курсы пользователя
- `GET /api/user/tracks` - получить треки пользователя
- `GET /api/user/achievements` - получить достижения пользователя
- `GET /api/user/notifications` - получить уведомления пользователя
